# 《主角生存决战》V9.2：手推汽车3D战场

## 这次升级

游戏主入口改为“手推汽车大乱斗”，旧版九英雄保留在 `classic_game.html`，并可从新版主菜单返回。新版全部以 3D 程序化几何模型构建（不是已经制作好的高精度 GLB/FBX 美术模型），使用随包提供的 Three.js 渲染库，不需要联网下载游戏引擎。

## 操作方法

- **按住车尾**：汽车持续向车头方向加速。
- **推车左侧 / 右侧**：车身向对应方向横移。
- **按住车身中心拖动**：汽车按拖动动作转向旋转。
- **从车身向车头方向快速滑动**：汽车跳起并向前冲刺（2.7 秒冷却）。
- **氮气按钮**：消耗 25 点能量冲刺；收集蓝色补给圈恢复能量。
- **辅助键**：直接推车不顺手时可打开额外控制按钮。
- **电脑键盘**：W/S 前后；Q/E 横移；A/D 转向；空格跳冲；Shift 氮气；P 暂停。

## 游戏玩法

1. 90 秒闯关：收集 10 颗星星取胜，途中有路障、跳台和能量补给。
2. 汽车大乱斗：与 5 辆 AI 车辆碰撞竞技，淘汰全部对手获胜。
3. 自由驾驶：无限时间练习车辆操作、横移、腾空和氮气。

车型：闪电跑车、越野战车、钢甲战车，速度、耐久和跳跃/碰撞表现不同。

## 打开游戏

电脑：解压 ZIP，双击 `index.html`，然后选择车辆与玩法，点击“进入3D汽车战场”。Windows 用户也可双击 `launch_windows.bat`。

iPhone：要直接从 Safari 打开游戏，建议把 ZIP 解压后的 `index.html` 和 `classic_game.html` 上传到你自己的网站或静态网页托管服务后，访问 HTTPS 地址。聊天文件链接不是正式在线网址。
