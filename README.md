# 玩具大比拼 V9.0

## 开始游戏

电脑上解压后直接用浏览器打开 `index.html`。点击右上角 **模式 → 主角生存决战**。网页内置运行依赖，可以离线玩。发布到静态网站时，将 `index.html` 上传到网站根目录即可。手机可在浏览器中打开发布后的网页。

## 主角生存决战

- 临港街区有仓库、消防站、公寓、维修车间和路障。建筑能挡住移动和射击，敌人会尝试绕路。
- 卡宾枪弹匣 24 发。弹匣打空会自动换弹，也可以手动换弹。战术刀需要近身。
- 70 名敌人开局入场。击杀可获得技能升级点，在技能键旁点小 **+** 升级。达到击杀节点可选择新技能。
- 点击小地图可放大或缩小。结算后点 **再来一局** 重开。

| 操作 | 电脑 | 手机 |
| --- | --- | --- |
| 移动 | WASD 或方向键，Shift 快跑 | 左侧摇杆 |
| 攻击 | 空格，或用鼠标点击场景瞄准 | 按住右下角攻击键，拖动可调整射击方向 |
| 切换武器 / 换弹 | Q / R | 底部的切换 / 换弹 |
| 技能 | 1–5 | 点击释放，拖动瞄准，可拖到取消区 |
| 暂停 | Esc | 右上角暂停 |

网页包含 Three.js 0.170.0 和 cannon-es 0.20.0，授权声明在 `index.html` 内。
